# Code of Conduct

MetaSheet-Guard contributors are expected to participate respectfully and in
good faith.

Unacceptable behavior includes harassment, discriminatory language, personal
attacks, deliberate intimidation, sustained disruption, or publishing private
information without consent.

Project maintainers may remove comments, close issues, or restrict participation
when behavior is inconsistent with these expectations.

Report concerns to the project maintainers through the repository issue tracker
or the contact channel listed by the project once maintainers publish one.
